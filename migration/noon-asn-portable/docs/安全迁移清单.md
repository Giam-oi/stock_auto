# 敏感数据安全迁移清单

以下内容不在 ZIP 内，必须单独迁移：

- 六店 Noon API 私钥文件：`noon1-API.json` 至 `noon6-API.json`。
- 企业微信机器人 Webhook。
- 绿通申请表原文件。
- 约仓 Excel、库存表、订单表、PDF 和运行日志。
- `%LOCALAPPDATA%\NoonASNCreator\journal.json`，仅在旧电脑仍有未完成 `pendingAsn` 时迁移。
- 浏览器登录目录、Cookie、JWT、HAR/网络抓包和 OneDrive 缓存不得迁移进本 ZIP。

## 建议方式

- 使用 BitLocker 加密 U 盘、公司批准的加密网盘或密码管理器附件。
- 凭证复制完成后检查文件权限，只允许当前 Windows 用户读取。
- 不通过聊天、邮件正文、Git、公开网盘或普通 ZIP 发送私钥和 Webhook。
- 新电脑验证完成后，安全删除中转介质上的明文副本。

## Journal 特别规则

若旧电脑有创建结果不确定或 `pendingAsn`，必须复制 journal 到新电脑同一路径后再恢复。没有未完成任务时不要迁移旧 journal，避免把陈旧状态带到新环境。

迁移 journal 前先检查其中是否存在未完成任务。它属于运行状态数据，必须使用加密介质单独传输，不能提交 Git 或发到聊天中。
