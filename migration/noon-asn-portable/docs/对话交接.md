# Noon ASN 对话交接

更新时间：2026-09-02，时区 Asia/Shanghai。

## 稳定业务规则

- UAE 使用 `AE`，普通预约默认仓库 `AUH01S`；KSA 使用 `SA`，默认仓库 `RUH01S`。
- 用户明确给出实际仓库时使用该仓库，不自行切换其他仓库。
- 一个约仓工作簿对应一个 ASN；手工清单或截图按店铺编号分组，每个店铺分组一张 ASN。
- 创建前按 SKU 和数量精确查重。创建结果不确定时优先恢复，禁止重复创建。
- 仓储类型无法识别时按批准规则使用标准类型和 `1,1,1,1`；Noon 可建目录没有 SKU 时不能绕过。
- 创建后精确核验、Seal，再次确认 `sealed` 后才写回或报告成功。
- 普通预约成功必须同时存在 `scheduled`、仓库、日期和时段四个字段。
- “下午”默认 `12:00-18:00`，选择范围内最早时段，除非用户指定具体时段。
- 企微通知不带产品名，必须带站点、数量、店铺、ASN、送仓日期和时间；未预约成功不发成功通知。
- 绿通表只追加、不删除、不覆盖，按 ASN 去重，送仓日期留空。
- 普通预约成功后不追加绿通表；无普通容量且仍需人工申请时才追加。
- 只接受 Noon 原始 PDF，禁止生成、打印或转换替代 PDF。
- OneDrive/SharePoint 原表写回优先通过 Microsoft Excel/Office 保存。写回前关闭占用程序，写回后重新读取、释放句柄，并等待 OneDrive 显示同步完成后再打开。
- 容量查询只读；创建、Seal、取消、预约、绿通申请、通知和工作簿写入均按具体范围单独授权。
