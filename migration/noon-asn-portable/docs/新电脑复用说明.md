# Noon ASN 项目新电脑复用说明

本包用于在另一台 Windows 电脑上恢复当前 Noon ASN 工作流，包括 Codex 技能、项目源码、可执行程序、业务规则和对话交接状态。

## 包内内容

- `skill/noon-asn-operations`：Codex Noon ASN 技能。
- `program/NoonASNCreator`：无需 Node.js 的 Windows 可执行程序。
- `project/stock_auto`：供 Codex 继续维护的源码与设计文档。
- `docs/对话交接.md`：长期规则和截至打包日的活动状态。
- `install.ps1`：安装技能、程序、源码并创建本机配置。
- `verify-package.ps1`：检查包内是否混入凭证、业务表或日志。

`NoonASNCreator.exe` 当前用于 UAE 文件夹批量创建、核验、锁单和写回。KSA、容量查询、普通预约、取消、绿通和 GRN 对账由 Codex 按已安装技能及脱敏 API 参考执行。

## 安装步骤

1. 在新电脑登录 Codex，安装 Google Chrome 和 Microsoft Excel。OneDrive/SharePoint 原表写回使用 Office 感知的保存方式，不使用 WPS 代替。
2. 将 ZIP 解压到普通文件夹，不要直接在压缩包内运行脚本。
3. 通过加密 U 盘或公司批准的安全渠道，单独复制以下数据：
   - `noon1-API.json` 至 `noon6-API.json`；
   - 当前使用的 `绿通申请表模板.xlsx`；
   - 仍需继续处理的约仓业务表。
4. 在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 `
  -ProjectRoot "D:\codex\stock_auto" `
  -ProgramRoot "D:\NoonASNCreator" `
  -CredentialDirectory "D:\noon-api" `
  -GreenChannelWorkbook "D:\桌面\绿通申请表模板.xlsx"
```

没有 D 盘时可省略参数，脚本会使用当前用户的 Documents 目录。

5. 单独设置企微 Webhook，不要写进项目或压缩包：

```powershell
[Environment]::SetEnvironmentVariable(
  "NOON_ASN_WECOM_WEBHOOK_URL",
  "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的密钥",
  "User"
)
```

6. 运行预检：

```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\.codex\skills\noon-asn-operations\scripts\preflight.ps1"
```

7. 完全退出并重新打开 Codex，在 Codex 中打开安装后的 `stock_auto` 项目。
8. 新建任务并发送：

```text
请先读取项目 docs/对话交接.md，并使用 $noon-asn-operations 继续 Noon ASN 流程。先做只读预检，不执行任何创建、锁单、取消、预约或通知。
```

## 验收

先做只读验证，不要用真实业务表直接测试写入：

1. 预检显示六份凭证、EXE 和绿通表均存在。
2. Codex 能自动发现 `$noon-asn-operations`。
3. 使用一个已知 ASN 做只读状态查询，确认店铺和站点正确。
4. 使用一份测试约仓表完成创建和锁单，人工核对 Noon 后台。
5. 只有预约四字段全部正确后才验证企微通知。

## OneDrive 原表写回

1. 写回前关闭目标文件的 Excel/WPS 窗口，并确认 OneDrive 已完成此前同步。
2. 对 OneDrive/SharePoint 原文件使用 Microsoft Excel/Office 感知的保存方式；不要用整体重写 `.xlsx` 的方式直接覆盖同步中的原文件。
3. 保存后重新读取目标单元格并确认 Excel 已释放文件。
4. 等 OneDrive 显示“已同步”后再打开原表。
5. 若打开后数据回退或提示占用，先停止写入并关闭 Excel；核对云端与本地版本后只恢复表格写回，不得重建 ASN。

## 源码维护

包内已包含编译后的 `dist` API 模块，Codex 可直接读取当前实现。若需要运行测试、修改源码或重新构建 EXE，再安装 Node.js 22，并执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -InstallSourceDependencies
```

## 限制

Codex 本地技能、配置和项目目录不会仅靠登录账号自动恢复，必须安装本包。原始对话逐字导出不在当前接口能力范围内，本包使用结构化交接文档保存稳定规则、关键决策和活动状态。普通预约容量与 ASN 状态必须在新电脑上实时查询，不能只信打包时快照。
