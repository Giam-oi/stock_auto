Noon 店铺自动登录 4.2.2
======================

本版本不读取或写入 Noon Cookie，也不使用 API JWT 模拟网页登录。它使用每个 Chrome
Profile 已经完成的正常网页登录会话，定期打开后台临时标签页检查 FBN，并通过访问受保护
页面保持会话活跃。

首次升级
--------

1. 双击 `安装扩展.cmd`。
2. 在店铺1至店铺6的 `chrome://extensions` 页面找到原 `Noon 登录助手`。
3. 点击该扩展卡片上的刷新按钮；如果扩展不存在，则开启开发者模式并加载
   `Noon登录助手扩展` 文件夹。
4. 扩展名称升级后显示为 `Noon 会话监控器`，版本为 4.1.0。

使用
----

双击 `Noon店铺会话监控.exe` 可立即检查所选店铺并配置30分钟后台监控。检测到掉线时，程序按店铺编号从新版 Outlook 对应邮箱读取本次新验证码并自动登录。

双击 `Noon六店自动登录.exe` 会在后台检查店铺1至店铺6，并自动登录掉线店铺，不显示控制台窗口。运行 `安装每日自动登录.cmd` 可安装每天 09:40 和 14:00 两次固定任务；`卸载每日自动登录.ps1` 可移除该任务。

双击 `Noon六店看板.exe` 会先确认六店登录状态，再分别用店铺1至店铺6的 Chrome 个人资料打开对应 Store Dashboard 窗口。

推荐长期运行方式：双击发布目录中的 `安装常驻监控.cmd`。它会注册当前用户登录和工作站解锁触发器，并立即启动单实例常驻进程。常驻进程每30分钟统一检查六店，扩展仅作为备用。电脑待机期间无法保活，唤醒后计划任务会确保常驻进程恢复。

安装后程序显示在 Windows 系统托盘（可能被收纳进隐藏图标区），不再显示可误关的黑色控制台窗口。双击托盘图标查看六店状态；右键可立即检查、打开日志目录或退出。关闭状态窗口只会隐藏，只有右键选择“退出监控”并确认才会停止本次运行。

手动常驻命令：

`Noon店铺会话监控.exe --resident --store all --site UAE --page dashboard --interval-minutes 30`

持续监控到指定时间：

`Noon店铺会话监控.exe --store all --site UAE --page dashboard --interval-minutes 30 --monitor-until 2026-08-12T09:30:00+08:00`

持续模式由 EXE 统一调度，扩展不会同时触发第二轮检查；若 EXE 停止约两个检查周期，扩展会自动接管后台保活。同一店铺持续掉线时只打开一次登录页。

检查结果写入：

`%LOCALAPPDATA%\NoonStoreLogin\session-monitor.jsonl`

掉登录时，程序会报告具体店铺并打开该 Profile 的登录页。重新正常登录后，下一轮检查会
自动恢复为正常。

安全与运行条件
--------------

- 扩展权限仅为 `alarms`、`storage`、`tabs`、`scripting` 和 Noon/本机桥域名。
- Outlook 邮箱必须在新版 Outlook 中命名为 `店铺1` 至 `店铺6`，并与 Chrome Profile 一一对应。
- 验证码只在内存中短暂传递，不写入日志；程序只接受发码请求之后新出现的 Noon 验证邮件。
- 扩展不具备 Cookie 权限。
- Chrome 需要保持运行，扩展的30分钟闹钟才能持续保活。
- 电脑休眠期间无法保活；唤醒后扩展会立即重新检查。
- Noon 服务端主动撤销或其他设备重新登录时，保活不能避免掉线，只能及时发现。
