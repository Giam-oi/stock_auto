# Noon 会话监控托盘程序设计

## 目标

把现有 `Noon店铺会话监控.exe --resident` 改为 Windows 系统托盘程序，避免常驻控制台窗口被误关，同时保留清晰、可控的查看与退出入口。

## 用户体验

- 计划任务启动常驻模式时不显示控制台窗口。
- 系统托盘显示一个 Noon 会话监控图标；Windows 可将它收纳到“隐藏的图标”区域。
- 单击或双击图标显示简洁状态窗口，列出店铺1至店铺6的最近状态与检查时间。
- 关闭状态窗口只隐藏到托盘，不结束监控。
- 右键菜单提供：
  - `查看六店状态`
  - `立即检查`
  - `打开日志目录`
  - `退出监控`
- 只有选择 `退出监控` 并确认后才停止常驻进程；Windows 计划任务下一次登录或解锁时仍会重新启动。

## 架构

保留现有 Node/TypeScript 监控核心与单实例锁。新增一个小型 Windows 原生托盘宿主，负责图标、菜单、状态窗口和生命周期；它启动并托管监控循环，通过本地状态文件读取每轮六店结果。监控核心继续负责 Chrome Profile、扩展桥、检查节奏和 JSONL 日志，托盘层不接触 Noon Cookie、密码、OTP 或页面内容。

为避免引入庞大的桌面框架，优先使用轻量 Windows 托盘实现，并在打包后保持单一用户入口。若托盘依赖无法可靠打入当前 `pkg` EXE，则发布一个同目录的小型托盘启动器，由计划任务启动托盘启动器，再由它隐藏启动监控 EXE；对用户仍表现为一个托盘图标。

## 状态与错误处理

- 图标绿色：最近一轮六店全部正常。
- 图标黄色：存在 unavailable 或尚无结果。
- 图标红色：至少一个店铺确认跳转 `login.noon.partners` 或标题为 `Partners Login`。
- 状态窗口只读取 `%LOCALAPPDATA%\NoonStoreLogin` 中由本工具写入的结构化状态，不读取浏览器存储。
- 常驻循环异常时托盘仍存活并在下一周期重试；连续异常显示黄色状态。
- 托盘宿主异常退出时，计划任务按现有设置重启。

## 安装与兼容

- 更新现有 `NoonStoreSessionMonitor` 计划任务，使其启动隐藏/托盘入口。
- 保持用户登录与工作站解锁触发器、单实例保护和每10分钟检查。
- 安装脚本可覆盖升级现有任务；卸载脚本删除任务并停止托盘与监控进程。
- 支持当前 Windows 机器，不更改 Chrome Profile、扩展或登录数据。

## 验证

- 状态聚合、颜色选择、立即检查信号和安全退出逻辑使用自动化测试覆盖。
- 完整测试、类型检查与 Windows 打包通过。
- 实机确认：计划任务运行、没有可见控制台窗口、托盘图标存在、关闭状态窗口后进程仍在、立即检查写入六条新结果、退出菜单能停止进程。
